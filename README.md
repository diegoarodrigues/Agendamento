# Agenda

Aplicação de agenda/calendário em React (Vite) com API Node e PostgreSQL.

## Requisitos
- PostgreSQL em execução e variável de ambiente `DATABASE_URL` configurada
  (ex.: `postgres://usuario:senha@localhost:5432/agenda`)

## Backend
```bash
cd backend
npm install
npm run dev
```

## Frontend
```bash
cd frontend
npm install
npm run dev
```
